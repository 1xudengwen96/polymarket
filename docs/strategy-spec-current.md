> 本文是运行中策略的权威描述，随配置/代码变更更新。
> 历史证据与裁决：docs/tail-capture-strategy.md、docs/profitability-verdict.md。

## 1. 运行形态

- 模式：paper（纸面撮合，真实行情流驱动，不实盘下单）；LIVE 双开关未启用
- 资产：**BTC / ETH** 两资产跑主策略（2026-08-16 晚收窄：SOL 2 天鹅周末集中、
  BNB 1 天鹅、DOGE/HYPE maker 成交率 9-18% 吃不到筹码——详见 config/assets.yaml 停牌注释）；
  BTC 另跑 mid_capture 中段实验；XRP 全停（fade 实验终止，结论见 §6）
- 结算规则：逐市场读取 `cryptoMarketConfig.twapLookbackSeconds`（当前各资产均为 TWAP60），
  RTDS 同时订阅 30s/60s 两个流按市场 lookback 匹配
- 本金：1000 USDT（每笔 5 USDC = 市场最小下单量）

## 2. 唯一入场模块：尾部买方（Tail Capture）

**方向性入场已永久禁用**（`entry_min_gross_edge: 99` + 状态机硬禁用守卫）。

每个窗口（5 分钟）每秒评估一次，**全部条件满足才发出一个买单**：

| 条件 | 值 |
|---|---|
| 结算参考价 PTB | 已捕获（缺失则整个窗口不可交易） |
| 剩余时间 | ≥ 10 秒 |
| 本窗口去重 | 无已发挂单/持仓（`tail_pending`/`tail_held`） |
| 资产内锁 | 同资产无其他窗口的在途持仓（**跨资产互不阻塞**） |
| 价格区间 | UP 或 DOWN 的 ask ∈ [0.98, 0.999) |
| 模型闸门 | **已关闭**（`use_model_gate: false`，纯价格闸门；依据：静态 EV 无过滤 +0.65%/笔，过夜 17/17 触碰全胜而模型全误拒） |
| 99¢ 桶 unsafe 标记 | 保留（校准数据：0.99+ 桶实际胜率 < 市场价时该侧禁用） |
| 挂单价 | min(bid+1tick, ask-1tick)，四舍五入到有效 tick，且 ≥ 0.98 |
| 仓位 | min(权益 × 0.5%, 100 USDC) = **5 USDC**（1000 本金） |
| 风控预检 | 见 §5 |

**订单类型**：BUY、限价、post-only、GTD（过期时间 = 窗口结束前 5 秒）。
**成交条件**（纸面撮合=真实成交流驱动）：有卖出成交击穿我方价位，且排在前面的同价挂单被吃完。

## 3. 持仓期间与出场

成交后（`tail_held`），每秒评估：

1. **盈利 ≥ 3 tick（0.3¢）**：
   - maker 出场：挂 avg+3tick 的 post-only 卖单（GTD 至 t_end-5s，`exit_pending` 去重）
   - 若买价已穿越目标价（post-only 会穿越簿口）→ 转 **FAK 市价卖**（吃当前买价）
   - 挂单过期未成交 → 下一 tick 重新评估
2. **未达 3 tick**：**持有到结算，不设止损/时间止损**（吃 1-1.5% 结算 EV；反事实分析：
   早出场多赚 5%/笔，但代价是 1% 仓位从锁盈变全亏，且占用持仓名额降低频率——保留出场）

## 4. 结算

- 窗口结束：RTDS TWAP 流给出 final → 自结算 `UP ⇔ TWAP_L(t_end) ≥ PTB`
- 胜方每股 $1、败方 $0，PnL 记账扣除费用（taker 1bp）；随后与 gamma 官方结果对账（dispute 记录）
- 结束前 5 秒强制撤单；最后 10 秒禁止新单

## 5. 风控（组合级）

| 限额 | 值（1000 本金，7 资产） |
|---|---|
| 组合未对冲敞口 | **随资产数扩展**：max(1%, 0.5% × 资产数) → 7 资产 = 35 USDC（7 笔并发） |
| 单窗口名义 | 200 USDC |
| 全市场占用 | 10% = 100 USDC |
| 单日亏损 | **-1% × √资产数** → 7 资产 = -26.5 USDC → 熔断 |
| 单小时亏损 | -0.5% × √资产数 → -13.2 USDC → 冷却 |
| 连亏 | 6 笔 → 冷却 12 窗口 |
| 最大回撤 | -3% = -30 USDC → 终止（kill switch，不缩放） |
| 行情熔断 | 簿口停滞 1.5s / TWAP 停滞 5s / 异常成交 3 tick → 暂停 |

## 6. 其他模块（继承启用，很少触发）

- **xrp_fade（反向实验，已终止 2026-08-16 晚）**：maker 挂 bid+1tick 实测 18 单 0% 成交
  （翻盘是向上跳，挂单在下方结构性吃不到）；改 taker FAK 吃 ask 后 28 连亏 0 翻盘
  （盈亏平衡 2-3%）。历史 3/6=50% 翻盘率未复现 → 判定为旧样本尾部巧合，实验关闭，
  配置保留 `xrp_fade.enabled: false` 供复盘。
- **mid_capture（中段买方实验，独立账本）**：仅 BTC、ask∈[0.94,0.96)、剩余 ∈[10,60]s
  买热门侧（maker bid+1tick，5 USDC），持有到结算。与主 tail **同资产并行、同窗口互斥**
  （tail 先评估优先；mid 守卫 tail 状态、tail 守卫 mid 状态；mid 挂单 30s 未成交自动过期
  防阻塞主 tail）。依据：BTC 8/14-15 该桶两数据源 0 败（回测 70 + 纸面 12 样本），邻桶
  (0.90-0.94/0.96-0.98) 均负——疑似"中段共识价真空区"；95% CI 上界 4.3% vs 盈亏平衡
  败率 4.9% 未显著 → 2 天纸面裁决。**跨资产证伪（8/14-15）**：同桶 ETH 95.1% /
  SOL 93.8% / DOGE 90.9% / BNB 88.4% / XRP 97.4%——现象仅在 BTC 出现，
  是 BTC 特有还是 59 样本侥幸，只有 BTC 纸面样本能裁决 → 实验保留在 BTC。
  **出场 A/B 对照（2026-08-16 加）**：`exit_mode: ab` 按 market_id 奇偶各半——
  hold=持有到结算（原口径）vs profit3=+3tick 出场（复刻 tail；价格过 0.96 后
  tick=0.001，出场线几乎贴成本，冲刺即 FAK 落袋）。依据：BTC 天鹅推演中 mid
  出场线在崩盘前 18s 被击穿而 tail 从未击穿。订单 meta 记录 `exit_mode` 归属。
- **tail_hedge**：尾部持仓成交后，可选买对侧 ≤5¢ 保险（成本 ≤ 预期利润 20%，≤5 USDC）
- **arb**：up+down 卖价合计 < ~0.9947 时双买 FOK（真实盘口几乎不出现）
- 方向性 HEDGE/EXIT 状态机：随方向性入场禁用而闲置
