## 结论与建议

### 四个核心问题的答案

1. **市场定价基准**：市场在 T-240 的 Brier 0.173（粗糙）、T-60 的 0.031、T-10 的 0.0008（近乎完美）。
   市场信息含量随接近收盘单调上升——"边跑边定价"。
2. **边际预测力**：纯 BTC 路径/订单流特征自身有真实信号（Brier 0.083，远好于随机 0.25），
   但市场已吸收大部分；全模型相对市场基准的增益集中在 **T-60 桶（Brier 0.0226 vs 0.0311，
   增益 27%）**，T-120 增益 3%，T-240 无优势，T-10/T-20 市场已完美。
3. **分时间桶独立模型**：无一致增益（T-60 独立 0.0231 ≈ 全局 0.0226）——全局模型足够，
   无需按桶训练。
4. **末段 10-20 秒行为**：**无统计显著边际信息**（末段收益系数 0.015 vs 早期 0.075，Brier 增益 0.000）。
   TWAP60 制下末段只占结算窗口 1/6，原假设"末段特殊行为"被定量证伪。

### 对策略的含义

- **Edge 存在但很薄**：T-60 桶 27% 的 Brier 增益 ≈ 平均 2.5% 的误差优势，
  在 6% gross / 4% net 阈值 + 1¢ 价差 + 费用下难以转化为可交易机会
  （5 天严格回测仅 6 次入场，-12.47 USDC）。
- **时间守卫已修正**：`entry_min_remaining_s` 90→30（原设置恰好排除了唯一有优势的 T-60 桶）。
- **尾部经济学**：98-99.9¢ 实际胜率 99.24% > 中值价 98.5%——尾部价格轻微低估，
  Tail Capture 理论空间 ~0.5-0.7%（扣费后很薄，需 maker 挂单 + 校准门槛）。
- **套利**：成交价近似无法测量（bid/ask 错位产生伪信号 71.7 万）；真实测量需订单簿历史
  （无公开 API）。从 Phase 3 的 0 次实际触发看，CLOB 层套利空间极小。

### 下一步建议（按优先级）

1. **T-60 专用策略变体**：仅在 remaining ≤ 60s 用模型 fair value 挂 post-only 单
   （吃价差而非跨价差），配合 maker 返佣，用回测量化"薄 edge 的可变现性"。
2. **模型升级**：LightGBM + 更多路径特征（TWAP 斜率、波动结构、成交强度），
   目标把 T-60 的 Brier 优势从 27% 提到 40%+。
3. **Tail Capture 独立验证**：以 99.24% 经验胜率校准门槛，maker 挂单模拟独立回测。
4. 放弃末段（T-10/T-20）策略假设——数据不支持。
