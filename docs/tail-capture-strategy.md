# 5m 市场可盈利策略：尾部买方（Tail Capture）——证据与裁决

> 最终答案：**有**。5m 市场存在一个统计显著的正期望策略：在 98-99.9¢ 买入高概率侧，
> 持有到结算。**11 天 3168 窗口回测 +451.7 USDC（+4.52%），PF 4.69，MaxDD 0.54%；
> maker 出场变体 +479.8（PF 5.90）**。结算体制切换（8月7日现货→TWAP30）已验证并
> 按体制拆分：当前 TWAP 体制 7 天 +201.3（taker）/ +227.6（maker）。
> 完整证据链见 `tail-evidence-11d.md` 与 `profitability-verdict.md`。

## 一、策略原理：favorite-longshot bias

市场**系统性低估高概率侧**。静态 EV 检验（3617 个样本，买 ask+1tick 持有到结算）：

| 剩余时间 | UP 实际胜率 | UP ROI/笔 | DOWN 实际胜率 | DOWN ROI/笔 |
|---|---|---|---|---|
| T-120 | 100.0% | +1.31% | 98.6% | -0.18% |
| T-60 | 100.0% | +1.03% | 99.2% | +0.28% |
| T-30 | 100.0% | +1.00% | 99.5% | +0.51% |
| T-20 | 99.6% | +0.56% | 99.6% | +0.55% |
| T-10 | 99.7% | +0.59% | 99.8% | +0.75% |
| 合计 | | **平均 +0.65%/笔** | | |

解释：98.5¢ 的价格隐含 98.5% 胜率，实际胜率 99.2-99.8%——市场把尾部风险高估了
1-2 倍（favorite-longshot bias 在短窗口预测市场的实证表现）。

## 二、实现要点（此前三个 bug 全部修复后才生效）

1. **缓冲阈值**：原 1.5% 缓冲远超真实 0.5-0.7% edge → 改为 0.3%（校准概率 ≥ 价格+0.3%）。
2. **下单方向**：dispatch 曾把 TAIL_CAPTURE 当 SELL 下单（从未正确执行）→ 修复为 BUY GTD post-only。
3. **仓位堆叠**：曾每秒重发单、跨窗口累计 4 个尾部仓（单次亏损 -195）→
   每窗口单挂单 + 全局单持仓 + 挂单去重。
4. **免止损**：尾部持仓不设止损/时间止损（吃结算 EV），仅 ≥3 tick 利润时提前卖出。
   出场推荐 **maker 变体**：挂 avg+3tick post-only GTD（t_end-5s 过期），未成交持有到
   结算兜底，穿越簿口时回退 taker FAK（11 天 A/B：maker +479.8 vs taker +451.7）。

## 四、风险与诚实的保留意见

1. **黑天鹅频率样本仍不足**：11 天 3 次（全部在 TWAP 体制，0.38%/笔，其中 2 次在
   结算切换日 8月7日）。需要更长运行样本确认频率稳定性。
2. **资金口径**：回测引擎默认初始本金 1 万 USDC（`config/risk.yaml`
   paper_starting_equity）。按比例缩放：**1000 USDT 本金 → 每笔 5 USDC（市场最小
   下单量，1000 是策略可行下限）、日收益 ≈4.1 USDT（taker）/ ≈4.3 USDT（maker，
   11 天口径）**。精确数字以 1000 本金回测为准（backtest-report-tail4-1000-*.md）。
   扩大仓位（>50 USDC/笔）将增加滑点并降低成交概率（尾部簿口深度有限）。
3. **成交模型保守性**：回测用合成簿（200×0.5=100 股/档）；maker 队尾排队假设偏乐观，
   真实尾部簿口行为需 Paper Trading 验证。
4. **结构风险**：favorite-longshot bias 可能因其他套利者进入而衰减；
   结算配置仍在变动（8月14日样本显示回看窗口回到 60s），部署时必须逐市场读取。

## 五、下一步（按优先级）

1. Paper Trading 该策略 2-4 周（≥1000 笔），校验真实成交率与 EV（1000 USDT 口径
   每笔 5 USDC 即最小单量，成交难度应低于回测假设）。
2. 若通过 → 极小资金实盘（每笔 5-50 USDC），人工确认后逐步调整。
3. 容量研究：尾部窗口成交量分布 → 可部署资金上限。
4. 定期重训模型+校准，监控 bias 衰减与结算配置变化。
